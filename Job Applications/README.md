# Job Applications

Company packs live under `companies/`. Shared form answers live in `General Application Info/`.

## Layout

```
Job Applications/
  companies/          ← Ashby, Caliber, Slate, …
  General Application Info/
  _template/
  _archive/
  INDEX.md
```

## Files in each company folder

- `Cody Duke Product Design Resume.pdf`
- `Cody Duke Product Design Cover Letter.pdf`
- `Job.md` — posting details, in the same format every time

Interview notes, offer notes, and follow-ups go in that same company folder:

- `Interviews.md`
- `Offer.md`

`General Application Info/reference.md` holds reusable form answers. It is not a company, and it is not listed in `INDEX.md`.

Copy `_template/Job.md` when a new company starts. Then add a row to `INDEX.md`.

Older exports sit in `_archive/`. Use the PDFs in the company folders, not those.
