# CRO: skill → pipeline → revenue story

**Jira:** None  
**Status:** Not started  
**Solves:** Initiative problem 4, as a designed surface (not only a write-up)

## Summary

Design how a CRO or VP of revenue sees a defensible skill → pipeline → revenue story for the business and the board.

Jordan already ran a skill-vs-performance overlay by hand. He still does not trust pipeline math. The job is not a bigger OSR heatmap. It is a story he can stand behind: where skill is associated with early-stage leak (close rate), what would have to be true for a dollar claim, and what is still a wet thumb.

This is in scope because Cody chose to design it, not only articulate it. It stays honest: no fake ARR.

## In

- On-system Figma, enough to walk in the founder interview
- Roll-up of the same model as E.skill-revenue-model (do not invent a second theory)
- Close rate vs win rate if we use Jordan's split
- Uncertainty, sample size, and "what we still cannot claim"
- How this is the same objects the manager uses (team → skill → deals), not a disconnected executive dashboard

## Out

- A live BI product or quota/attainment system
- Dollar impact presented as fact on today's CRM fields
- Enablement's one-size-fits-all catalog (Reid) as a CRO UI
