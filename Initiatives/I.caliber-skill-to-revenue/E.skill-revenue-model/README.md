# Skill → deals → revenue model

**Jira:** None  
**Status:** In progress  
**Solves:** Initiative problem 1

## Summary

Write the point of view Caliber asked for: how skill proficiency (OSR) relates to deal outcomes and revenue. State it plainly. Write the assumptions. Say what is correlation. Say what we will not claim. Name the data we need next and the proxy we use until it exists.

This is a written epic. If a diagram helps the founder walkthrough, it lives here. It is not a Figma dashboard.

## In

- A one-page model a founder can disagree with
- Assumptions and confounders (book quality, fit, inbound vs outbound, tenure, comp, messy CRM)
- Now / next / later: stage+stall proxy → amount+win/loss → quota/CRO
- Uncertainty rules for the UI (sample size, coverage, "associated with")
- Why Value Based Discovery is the first skill (or a documented change if we pick another)

## Out

- Formulas fitted to data
- Dollar claims on today's fields
